Stacking, without writing it yourself

Neither box carries any positioning of its own, and neither uses the demo stylesheet's .frame, which already contains this same stacking. layer.css puts the poster and the video in the same place and makes both cover the box, which is the one thing every consumer previously had to invent. The left box uses a bare <img>; the right uses <picture>, which needs a different selector because object-fit applies to replaced elements and a picture is not one.
